Hi, this is my first real project. This password checker takes your input(uses getpass so your password isnt visible to others) and scores it based on length and use of character types. It first checks if the password is in the most common 100,000 passwords, then proceeds to check whether it is atleast 8 characters long and it has more different characters than half its length. If those are fine, it gives you a score and also a feedback on what to improve
